# v1.3 PuTTY Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1.3.0 opt-in PuTTY compatibility launcher MVP.

**Architecture:** Add pure parsing and shim-management modules, then integrate them into the existing App state machine and authentication flow. Keep normal startup unchanged and make PuTTY direct sessions transient.

**Tech Stack:** Rust 1.95, tokio, ratatui, crossterm, anyhow, serde/toml.

---
