# v1.2 Curl Install Script Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a macOS/Linux `curl | sh` installer that selects the correct GitHub Release asset, verifies checksum coverage, and installs `sush`.

**Architecture:** Keep installation logic in `scripts/install.sh` and verify it with an offline shell test that stubs platform and download tools. The script maps OS/CPU to cargo-dist asset names, downloads the archive and checksum file, verifies the archive checksum, extracts `sush`, and installs it to a user-selected directory.

**Tech Stack:** POSIX `sh`, `curl`, `tar`, `unzip`, `sha256sum` or `shasum`.

Create `scripts/test-install.sh` with fake `uname`, `curl`, `tar`, `unzip`, and `shasum` commands. Cover macOS arm64 latest install, Linux x86_64 pinned version install, custom install dir, and unsupported platform failure.

- [ ] **Step 2: Verify RED**

Expected: FAIL because `scripts/install.sh` does not exist.

- [ ] **Step 3: Implement installer**

Create `scripts/install.sh` with:
- `SUSH_VERSION` or first argument support, default `latest`
- `SUSH_INSTALL_DIR` support, default `$HOME/.local/bin`
- OS/arch mapping for macOS arm64/x86_64 and Linux arm64/x86_64
- archive and checksum download via `curl -fsSL`
- checksum verification via `sha256sum` or `shasum -a 256`
- tar/zip extraction, binary discovery, install, and executable permission

- [ ] **Step 4: Verify GREEN**

Run: `sh scripts/test-install.sh`

Expected: PASS with no output.
