# sush.sh (sush) v1.1.0 需求文档

## 版本目标

v1.1.0 聚焦 SSH 嵌入式终端和 SFTP 文件浏览的基础体验补齐。

## 需求细则

### F1: SSH 终端 scrollback

**规则**：
- SSH 嵌入式终端保留历史输出，不只显示当前屏幕内容
- 支持通过鼠标滚轮查看历史输出
- 支持 `PageUp` / `PageDown` 查看历史输出
- 滚动查看历史时，普通键盘输入仍继续转发给远程 PTY
- 远程程序进入 alternate screen 时，滚动和翻页输入继续交给远程程序处理
- `Ctrl-\` 仍作为 SSH / SFTP 切换键，不转发给远程 PTY

### F2: SSH 终端文本选择与复制

**规则**：
- SSH 嵌入式终端普通屏幕下支持鼠标左键拖拽选中文本
- 鼠标松开时自动将选中文本复制到系统剪贴板
- 选区支持当前屏幕和 scrollback 历史内容
- 选中文本在 SSH 视图中高亮显示
- 远程程序进入 alternate screen 时，鼠标事件继续交给远程程序处理
- 复制失败时显示状态消息，不影响 SSH 会话

### F3: SFTP 返回上级目录

**规则**：
- SFTP 模式下按 `Backspace` 或 `←` 返回当前激活面板的上级目录
- 本地面板和远程面板分别按各自当前目录计算上级
- 已经位于根目录时保持在根目录
- 返回失败时显示状态消息，不改变当前目录

### F4: SFTP 当前列表模糊搜索

**规则**：
- SFTP 模式下按 `/` 进入当前激活面板的搜索输入
- 输入时只过滤当前目录列表，不跨目录搜索
- 搜索结果继续保留目录优先与文件列表选择行为
- `Enter` 确认当前过滤结果，`Esc` 取消并恢复完整列表

### F5: SFTP goto 跳转目录

**规则**：
- SFTP 模式下按 `g` 进入当前激活面板的目录跳转输入
- 输入绝对路径时直接跳转到该路径
- 输入相对路径时基于当前激活面板目录解析
- 本地和远程面板分别使用本地文件系统与 SFTP 目录列表验证目标
- 跳转失败时显示状态消息，不改变当前目录

## 验收重点

- SSH 输出超过一屏后可回看历史内容
- SSH 普通屏幕下可通过鼠标拖拽复制屏幕或历史输出文本
- SFTP 两个面板都能通过快捷键返回上级目录
- SFTP 搜索只影响当前目录列表，不改变当前目录
- SFTP goto 成功后刷新对应面板列表，失败时保留原路径
