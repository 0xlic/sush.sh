# sush.sh (sush) v1.2.0 需求文档

## 版本目标

v1.2.0 聚焦发布与分发体验增强，降低新用户安装、升级和验证二进制的成本，同时让发布流程更可检查、更少依赖人工记忆。

## 需求细则

### F1: 发布后验证脚本

**规则**：
- 提供一个可在本地运行的发布后验证脚本
- 脚本接收目标版本号或 tag 作为输入，例如 `v1.2.0`
- 脚本检查 GitHub Release 是否存在
- 脚本检查六个平台的 release asset 是否齐全：
  - `aarch64-apple-darwin`
  - `x86_64-apple-darwin`
  - `aarch64-unknown-linux-gnu`
  - `x86_64-unknown-linux-gnu`
  - `i686-pc-windows-msvc`
  - `x86_64-pc-windows-msvc`
- 脚本检查 checksum 文件是否存在，并能覆盖所有发布产物
- 验证失败时输出明确的缺失项并以非零状态退出

### F2: CI 增加 cargo check

**规则**：
- GitHub Actions 中增加 `cargo check`
- `cargo check` 必须在 pull request 或常规 CI 检查中执行
- CI 检查项与本地验证清单保持一致，至少覆盖 `cargo check`、格式检查和 lint
- CI 失败时应能从 job 日志定位失败命令

### F3: Release tag 与版本一致性检查

**规则**：
- Release workflow 在构建发布产物前检查 tag 与 `Cargo.toml` 的 `package.version` 一致
- tag 格式必须为 `v{MAJOR}.{MINOR}.{PATCH}`，预发布 tag 允许 SemVer 预发布后缀
- 当 tag 为 `v1.2.0` 时，`Cargo.toml` version 必须为 `1.2.0`
- 不一致时 workflow 必须失败，且错误信息指出 tag 与 manifest version 的实际值

### F4: README 安装、升级与 checksum 校验说明

**规则**：
- 英文 README 和中文 README 都要补充二进制安装说明
- README 说明如何选择当前系统和架构对应的 release asset
- README 说明如何升级已有安装
- README 说明如何下载并校验 checksum
- README 中的命令应避免依赖未说明的工具，必要工具必须在文案中说明

### F5: Homebrew formula 草稿

**规则**：
- 提供 Homebrew formula 草稿，优先支持 macOS Apple Silicon 与 Intel
- formula 草稿使用 GitHub Release asset 作为下载源
- formula 草稿包含版本号、sha256、安装二进制和基础 smoke test
- 本版本只要求生成可检查的草稿，不要求维护独立 tap

### F6: `curl | sh` 安装脚本

**规则**：
- 提供面向 macOS 和 Linux 的 shell 安装脚本
- 脚本根据操作系统与 CPU 架构选择匹配的 GitHub Release asset
- 脚本默认安装最新稳定版本，也支持通过环境变量或参数指定版本
- 脚本下载 checksum 并在安装前校验目标 asset
- 脚本允许用户指定安装目录，默认安装到常见用户可写目录
- 不支持的平台或架构必须输出明确错误并以非零状态退出

### F7: 发布文档与流程对齐

**规则**：
- `docs/ROADMAP.md`、`docs/ARCHITECTURE.md`、英文 README 和中文 README 的发布相关说明应与实现保持一致
- 发布流程仍以 `Cargo.toml` 的 `version` 字段作为唯一版本来源
- v1.2.0 开发期不提前修改 `Cargo.toml` 到 `1.2.0`，版本号只在正式 release bump 时更新

## 验收重点

- CI 能在常规检查中执行 `cargo check`
- Release workflow 能阻止 tag 与 `Cargo.toml` version 不一致的发布
- 发布后验证脚本能发现缺失的 release asset 或 checksum
- README 中英文均能指导用户完成安装、升级和 checksum 校验
- Homebrew formula 草稿包含可人工审核的下载地址、sha256 和安装逻辑
- `curl | sh` 安装脚本能在 macOS 和 Linux 上选择正确 release asset，并在 checksum 校验通过后安装
